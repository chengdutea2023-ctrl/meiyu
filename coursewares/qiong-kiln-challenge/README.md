## 1.7.2 温度分区说明

## 1.7.1 温控风险与重新点火

仅手动实时模型增加温控风险：模拟1350℃以上连续2秒触发一次炸膛，结束本窑，伴随短暂尘烟、碎屑、轻微震动及低沉音效；短时高温及时降温可以恢复。升温达到600℃后，未烧熟时低于300℃连续3秒会熄火；停止加热消耗，5秒冷却结束后点击“重新点火”继续。连点不能跳过或重置冷却。初始冷窑、已烧熟的正常出窑降温不会误判熄火。后台、指南或离开窑场暂停冷却计时，点击降温恢复；重新开窑清除风险状态。均为教学游戏规则，不代表真实窑炉操作或安全指导。

AI引擎、奖励和五题评分不变。新JSON保存`hazardVersion: hazards-v1`、熄火/重燃/炸膛事件及模拟时间，TXT以中文呈现；历史记录不改写。音效服从静音、后台和弹窗状态，每窑只播放一次；减少动态效果下无震动。以上持续高温规则替代1.7.0的即刻损坏阈值，原玩法仍可约30秒完成。

## 1.7.0 实时控火与动态烟气

“我来烧”改为连续模拟：点击一次加热/降温持续生效，仅保留两个控火按钮；在模拟1000–1200℃区间累计6秒，再降温至60℃完成，正常约30秒一窑，不控制会在1350℃过热。最长60秒。切出标签、离开窑场或打开说明时暂停，回来点击任一控火按钮继续；重复点同一按钮不加速。该连续模型独立于AI离散引擎，不改AI三动作、Q-learning、奖励或五题50+5×10评分，也不作同条件胜负比较。

## 操作流程

1. 入口验证后阅读两步说明，点击开始实验。
2. 手动用加热、保持、降温完成一窑；损坏或烧成不足也保留记录。
3. 进入教AI烧，选择“优先烧好”并学习、观察，再选择“优先节能”并学习、观察。
4. 完成2/2后查看实际对比数据，选择发现、回答五道实验思考题并提交。进阶设置中仍可调整参数与轮数，但不是必做步骤。

提交检查手动记录、两种指定预设、发现选择和五道题全部作答。合格与失败都算实验；评价总分100，完成占50、五题每题答对10分，模拟器合格率不直接决定成绩，不宣称自动理解文字质量。训练轮数默认3000，可在进阶设置改为300/1000/8000；提前停止保留实际轮数及测试结果，0轮不计完成。

## 模拟和算法

- 热度是 0–100 指数，初始 20；加热 +18、保持 −2、降温 −16，各步叠加均匀的 ±2 扰动。
- 热度 58–80 时烧成进度增加 1；累计 3 后降到 ≤35 合格。≥94 过热损坏，22 步截止。累计进度不因中途离开区间清零。
- 加热/保持/降温分别消耗 5/2/0 个能量单位。
- 每步奖励：`−能耗×能耗权重−耗时权重+新增烧成进度×合格奖励×0.08`；最终合格追加合格奖励，过热扣损坏惩罚，超时扣损坏惩罚的一半。过程奖励有明确说明。
- 状态为热度按 5 取整、烧成进度、操作步数；3 个动作；Q 表从 0 开始。更新为 `Q(s,a) += 0.24*(reward+0.97*maxQ(s',*)−Q(s,a))`，终止状态未来价值置 0。
- ε 从 0.9 递减至约 0.08，探索和并列动作均使用带种子的随机数。每轮的窑炉和动作随机种子独立派生。
- 训练窑炉种子为 `815+67*i`（最多8000轮），统一测试使用另一组 `1330001+47*j` 的30个种子，两组完全不重叠。测试不更新 Q 表，也不主动探索，未知状态及并列动作随机选择。
- 固定程序和各 AI 测试使用相同 30 个测试种子。单窑记录单独列出，不把一次成功当稳定合格率。不同奖励配置下的“平均奖励”不可直接横向比较。
- 每次训练真正执行状态转移及 Q 更新。曲线是每50轮的实际训练合格率，包含探索，因此与独立测试率不同。训练不保证成功或优于固定程序。
- 历史1.4.1及以前“重视节能”惩罚5会展示奖励失衡下不加热的失败策略；当前默认惩罚2，在争取合格的同时节能。仍可手动调为5观察失败，不隐藏真实结果；训练不保证成功率或节能幅度。

算法参考：[Farama Gymnasium 的 tabular Q-learning 教学](https://gymnasium.farama.org/tutorials/training_agents/frozenlake_q_learning/)。本实现为独立 JavaScript 模拟，未引入 Gymnasium 运行依赖。
