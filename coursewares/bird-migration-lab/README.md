# 候鸟迁徙实验室

- slug: `bird-migration-lab`；运行类型: `STATIC`；平台入口: `/`（映射到 `static/index.html`）。
- 保留地图、GPS 数据导入、迁徙路线、证据推理和科学报告。
- 过程评分维持原规则：路线数据 30 分、物种与季节 20 分、地点生态标注 20 分、证据推理 30 分；推理按文字长度分档，不是 AI 内容质量评价。
- 正式模式先验证启动信息，再上报 `STARTED`。先以 `text/plain` 上传科学报告，再保存 `COMPLETED`，避免含 charset 的 MIME 被平台拒绝。
- 保存失败后冻结首次报告并保留已上传附件，可重试保存；成功后才能通过课件内入口返回学生后台。
- 浏览器草稿按学生、学习任务和课件隔离；公共设备仍需正常退出并清理站点数据，草稿不是服务端备份。
- `?demo=1` 可本地预览，明确提示成绩不会保存。
