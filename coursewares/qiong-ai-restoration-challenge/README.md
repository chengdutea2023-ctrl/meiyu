智课 v3 BOTH 课件。React/Vite 前端和 Node.js 服务，独立运行，不依赖前两款课件。采用已选定的“考察手账”界面：展开笔记本、证据照片、红色批注与封存资料袋。

## 当前工作流：三步复原方案（workflowVersion 2）

1. 课外“上传我的线索”：建议1—3张，每张填写来源和一句发现；至少1张完整学生线索才能提交，教师审核通过后可进入课堂。准备期和课堂开放分别设置。
2. 课堂“我的线索”：主动选择1—3张审核通过的学生图片。历史教师备用图不显示、不计数，未采用图片折叠保存。
3. “我的复原方案”：写4—500字，说明怎样复原、依据是什么。默认标出口沿缺损，画布标画可选。
4. “展示我的成果”：至少成功生成1张AI修复图才能提交。PNG成果卡、结构化ZIP和平台COMPLETED全部保存成功后才显示已提交；成绩为null。旧版已提交的文字方案仍可查看，新提交须有成功AI图；修改方案后要重新生成，也可选用先前已成功生成的完整方案与图片，不能把新文字套到旧图。

学生每次成功打开课堂时，先弹出“这节课学什么、怎么玩？”：解释线索观察、带依据的方案、三步操作和AI输入/边界；点击开始、关闭或Esc后继续原有进度，可从“课堂指南”重新查看。说明不触发生成、不修改草稿或审核，不新增提交门槛。课外准备和教师审核页不弹此课堂说明。

AI修复为必做，一次只生成1张，输入仅为残损案例、主动选择的线索和方案。每学生任务最多三版，重置不补额度；明确失败最多手动重试一次，状态不明不重发，失败、状态不明或总额度不足时保留草稿，允许明确失败项重试或选用当前审核下已有的成功方案；没有成功图时不能提交，需联系教师处理服务/额度。遮罩外像素继续由合成保护。模拟AI不能冒充正式生成成果。

新版使用独立本机草稿键、version 2进度包和proposalId附件标识，不自动转换旧草稿。服务端复用原学生任务存储，session新增proposals，提供/api/proposals创建、查询、generate和retry；/api/history只读访问旧实验和已重置方案。旧分类、照片、审核、实验与报告原样保留；只有主动选中的学生线索进入新请求。重新开始保留照片和审核，可以恢复上次方案。课外图片可跨设备读取，课堂未提交草稿仍需进度包换设备。

三次机会的已用/剩余次数由服务端返回，保留重新开始前的用量；旧的未生成方案在首次生成时另存新版提示快照，不改写旧作品。新版提示优先执行学生指定材料/颜色，金色与钛合金按不同金属质感表达；参考釉色不能覆盖明确的材料要求。候选图默认仅画红色边框，内区不染红，可隐藏边框查看原色。历史生成图像素不回写；本次不自动调用真实AI，保留学生第三次机会和既有服务总请求上限。

## 运行和构建

仅构建/测试本课件使用 `npm run coursewares:restoration:build`、`npm run coursewares:restoration:test`；`coursewares:qiong:build/test/package`现代表三款全套，不再只代表修复。正式发布前执行 `npm run agent:check`；干净提交后使用 `npm run coursewares:restoration:package`生成标准ZIP及SHA-256。服务启动入口为`server/server.js`；依赖见`server/package.json`，不打包node_modules。

本地模拟预览显式设置`ALLOW_LOCAL_DEMO=1 AI_TEST_MOCK=1`，通过`?demo=1`进入。它回显目标图，只验证流程，始终显示“模拟服务测试，非真实AI结果”。正式部署设置两个开关为0；模拟开关在非本地演示模式下无效。不要向生产课件开放演示身份。

服务端配置：

| 变量 | 含义 |
| --- | --- |
| `PORT` / `HOST` | 平台分配，正式只监听回环地址 |
| `PLATFORM_API_BASE` | 服务端固定的平台API地址，用于逐次验证启动上下文 |
| `COURSE_SLUG` | 平台注入，验证课程归属 |
| `COURSEWARE_SLUG` | 平台注入，严格验证实际分配的课件短名 |
| `NEXT_PUBLIC_COURSE_BASE_PATH` | 平台注入，兼容课程子路径 |
| `COURSEWARE_DATA_DIR` | 包外独立持久化目录，不得位于static中 |
| `COURSEWARE_ENV_FILE` | 私密环境文件路径；不进入Git、ZIP、回复或日志 |
| `ARK_API_KEY` | 仅服务端读取的独立测试或生产凭据 |
| `ARK_IMAGE_MODEL` | 默认`doubao-seedream-5-0-flash-260915`，可由服务端替换 |
| `AI_MAX_REQUESTS` | 当前环境总请求上限，由私密配置及健康检查核对，不因重启清零 |
| `AI_TIMEOUT_MS` | 默认240000；网络结果不明会停在待确认状态 |

`AI_MAX_REQUESTS`计数包含已向服务发出的请求，持久化到数据目录，重启不清零。课堂每个学生任务最多三版单图效果，每版最多手动重试一次；状态不明的请求不能自动或手动当作失败项重发。正式上线前根据班级规模另行配置额度，不把测试上限当作长期容量。

## 数据与画布

三步版不要求三条约束、预测、三组对照、核验组、独立审查或逐组标记。平台启动和任务归属逐次校验，不新增数据库结构或学生登录体系。正式部署保持现有包外私密配置及总请求上限；本轮验收不调用真实AI。

修复操作区：前两阶段采用加宽画布与右侧资料/假设栏，工具放在图片上方。画布随屏幕自适应；“放大操作”进入独立编辑视图，初始至少150%，支持画笔、橡皮、撤销、1—4倍缩放、移动与适合画面，退出保留同一份遮罩。图片保持原比例，落笔坐标根据实际显示矩形映射至原图，拖动受边界限制。编辑画布不再弹出悬停预览，其他照片保留居中大图。

图片查看：取消悬停预览和双击入口，点击小图直接在课件中央打开大图；鼠标、触屏、Enter/空格操作统一。线索图片的查看按钮与下方勾选区分开，查看不会改变选中状态，已冻结或提交后仍可看图。修复画布仍只通过“查看大图”明确打开，不干扰画笔和移动。大图支持缩放、关闭、Esc和键盘焦点循环；关闭返回原位置，资料卡中按Esc先关闭大图、保留正在编辑的内容。

## 测试任务追加额度

普通学生每任务仍默认3次。私密环境`AI_TEST_ALLOWANCE`可为一个已核对身份的学生/任务配置`ownerId`、`proposalLimit`和`extraRequests`，仅运维配置生效，不接受前端、上传或重置请求修改。会话、方案接口和课堂指南统一显示本任务额度；已用计数、重置历史及请求日志继续累加，不清零。

`AI_MAX_REQUESTS`保留原有基础请求上限。测试追加请求只能由配置中的owner在基础额度用完后使用，重试也占用总请求上限；其他学生不能消耗追加测试预算。总上限为基础请求上限加授权的extraRequests。服务重启仍从原请求日志读取计数，必须先备份数据与私密配置，核对测试任务归属并获得追加预算授权；本次配置额度不自动发起生图。

## 线索特征直接关联（2026-10-27）

继续三步：选课前线索；在所选案例下识别、确认并采用可见特征，自动整理方案并生成；并排检查线索局部和修复局部后展示、提交。每张线索最多采用一条特征，可直接修改AI建议，至少采用一条。未采用图片不进入新方案生成；材料等额外想法独立保存为`creativeText`，不能覆盖已采用的特征。旧方案、已有结果和审核不原地改写，点击修改方案才进入新编辑方式。

`featureWorkflow:1`、`featureSelections`记录线索ID、部位、具体特征、原图归一化局部位置及学生确认来源。服务端从这些信息生成提示词，客户端自由文本不能覆盖采用要求；识图返回位置会从等比例留边的512像素输入换算回原始线索照片。`POST /api/evidence-jobs`分别创建`analysis`与`check`，`GET /api/evidence-jobs/:id`查询、`POST /api/evidence-jobs/:id/retry`仅重试一次明确失败。均沿用任务启动和教师审核门禁，课外凭证、教师身份及跨任务访问被拒绝。

识图只提出可见特征，不鉴定年代真伪。核对使用本次补配局部、对应遮罩及采用线索的局部，逐条返回`reflected/not_reflected/unclear`；只作观察提示，不出相关性总分或自动成绩。失败、超时或核对额度不足不会阻断已有真实生图作品提交。超时、服务重启中断或模型已返回但保存未确认时均不自动重发；相同图片/案例请求缓存复用，快速重复点击不再次调用。识图中的任务暂不能重置；已完成的观察缓存、计数与历史随本任务保留。

视觉调用独立读取私密配置`ARK_EVIDENCE_API_KEY`，使用已核对的`doubao-seed-2-1-pro-260915`；不会使用仅限Flash的生图Key，也不从其他服务文件自动读取凭据。`EVIDENCE_MAX_REQUESTS`与`EVIDENCE_BUDGET_CNY`默认0，真实调用关闭，须获得预算授权后配置。每次保守预留0.25元，最多5张512×512输入、文本/Schema字节上限12000、关闭思考、最多1300输出token，按当前官方Pro输入6元/百万、输出30元/百万token设防；预留金额不等于实际花费。请求与预留独立写入`evidence-request-count.json`，不消耗或重置原生图额度；`EVIDENCE_TEST_OWNER_ID`可将联调限于指定任务，`EVIDENCE_MAX_REQUESTS_PER_TASK`默认8。价格或模型变更须重新核对上限，不自动切换模型。

成果卡、资料包和投屏线索介绍同时保留“课前发现、本次采用特征、对应AI核对提示”，不借用其他方案的观察。进度包保留采用特征和创意；草稿仍为本机保存，课前图片及其审核继续跨设备读取。
