## 运行和构建

从仓库根目录运行 `npm run coursewares:qiong:build`、`npm run coursewares:qiong:test`。正式发布前执行 `npm run agent:check`；干净提交后使用 `npm run coursewares:qiong:package`生成标准ZIP及SHA-256。服务启动入口为`server/server.js`；依赖见`server/package.json`，不打包node_modules。

本地模拟预览显式设置`ALLOW_LOCAL_DEMO=1 AI_TEST_MOCK=1`，通过`?demo=1`进入。它回显目标图，只验证流程，始终显示“模拟服务测试，非真实AI结果”。正式部署设置两个开关为0；模拟开关在非本地演示模式下无效。不要向生产课件开放演示身份。

服务端配置：

| 变量 | 含义 |
| --- | --- |
| `PORT` / `HOST` | 平台分配，正式只监听回环地址 |
| `PLATFORM_API_BASE` | 服务端固定的平台API地址，用于逐次验证启动上下文 |
| `COURSE_SLUG` | 平台注入，验证课程归属 |
| `NEXT_PUBLIC_COURSE_BASE_PATH` | 平台注入，兼容课程子路径 |
| `COURSEWARE_DATA_DIR` | 包外独立持久化目录，不得位于static中 |
| `COURSEWARE_ENV_FILE` | 私密环境文件路径；不进入Git、ZIP、回复或日志 |
| `ARK_API_KEY` | 仅服务端读取的独立测试或生产凭据 |
| `ARK_IMAGE_MODEL` | 默认`doubao-seedream-5-0-flash-260915`，可由服务端替换 |
| `AI_MAX_REQUESTS` | 测试总调用上限；每个环境先设3，本地+上线共6 |
| `AI_TIMEOUT_MS` | 默认240000；网络结果不明会停在待确认状态 |

`AI_MAX_REQUESTS`计数包含已向服务发出的请求，持久化到数据目录，重启不清零。课堂每个学生任务最多两轮，每项最多手动重试一次；状态不明的请求不能自动或手动当作失败项重发。正式上线前根据班级规模另行配置额度，不把测试上限当作长期容量。

## 教学流程与数据

1. 资料导入支持图片、图片+CSV ZIP、手动编辑资料卡、课外任务单和CSV模板。建议筛选8—12张，不以数量评分。每张有效参考与核验资料应记录来源、特征、支持的判断和筛选理由。
2. 三条修复约束各绑定参考；最多3张进入生成。保留2—3张核验资料，生成后不能将参与过生成的图片改成核验资料。
3. 同轮冻结残损图、遮罩、提示词、模型与可控参数；A仅目标图，B目标图+等量干扰参考，C目标图+学生参考。随机性不能被解释为稳定因果。局部范围由最终像素合成保证，不宣称模型原生支持遮罩修复。
4. 三图同步缩放；每组添加具体位置、判断、理由与保留资料依据。允许“证据不足”“无法确定”。原图只能在服务器校验审查完成后获取。
5. 生成可读PNG和结构化证据ZIP；全部附件上传及COMPLETED成功后才显示保存。成绩为null，质量由教师评价。上传失败保留成功附件，重试按内容校验复用；修改内容会重新上传对应文件。

资料、任务与图片按已验证的学生、课堂任务和课件隔离保存。不新增平台数据库结构，不接触底座账号密码。课件只调用平台现有启动、附件和学习记录接口。浏览器保存本机草稿；进度包包含资料、约束、遮罩、审查和归档结果，不包含凭据。同一任务恢复关联原实验；其他设备或其他任务只恢复准备材料与假设，不冒充原任务生成，也不承诺跨设备云端续做。

## 素材来源与限制

来源、署名、授权及修改记录见`static/assets/provenance.json`与`sources.html`。教师照片作者Kcx36，CC BY-SA4.0；名称遵循来源标题，尚未逐件与馆方藏品编号复核。案例由已有四系罐照片制作人工口沿缺损；完整照片只存于`server/private/`，不进入生图请求。生成参考来自另一张照片的左侧器物，避免同图右侧目标器物泄漏。

备用包的三张参考是同一照片的不同裁切，并非三个独立证据；两张核验照片器类不同，只能做有限比较。它用于练习证据局限，教师应补充经过核对的同类器资料。纸张与资料袋是生成的界面装饰，不作为文物证据。楷体字体沿用仓库LXGW文楷，保留OFL许可证并裁剪为本地woff2。

## 本地验收与上线条件

自动测试覆盖像素保护、参考隔离、CSV/ZIP与损坏进度包、保存失败重试、重复点击、请求冻结、子任务失败、凭证过期、任务归属、重启与不明超时分类。界面检查包括1440×1024、1440×900、1024×768、768×1024、390×844。截图、平台接口证据和完整检查日志存于任务工作区，不混入标准包。

本地平台有一条明确标注“本地接口验收，非真实AI”的夹具记录，用于验证附件、教师学生查看和默认投屏，不能计为真实AI课堂验收。

真实AI联调、真实结果课堂审查和上线验收完成前，不执行生产发布。届时按现有runbook：检查干净提交与发布预检，备份数据库及相关配置，通过管理接口新建《邛窑AI探究》课程，登记新课件并分配端口，使用隔离测试课堂完成3张上线冒烟。保留原课程和真实班级安排。失败时停用新增课件并回退对应版本或配置，不用整库恢复覆盖后续业务数据。
