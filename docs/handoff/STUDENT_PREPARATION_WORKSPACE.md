# 学生课外准备页

2026-11-03。邛窑 AI 修复挑战的学生课外资料页面与教师审核工作台使用同一白绿操作风格，保留原有上传、资料编辑、审核和课堂返回规则。

## 页面

- 顶部：本次任务、学生、准备状态、刷新和三步进度。
- 主区域：本次保存的线索图片、出处、自己的发现、线索卡编辑、暂不采用/重新采用。
- 侧栏：准备要求、北京时间安排、老师反馈、提交与审核；通过后可返回学生平台。
- 手机改为单列，平板为双列图片与分区信息。图片始终完整包含在容器中，保留大图查看；线索卡弹窗支持 Escape、焦点约束及返回原触发点。

## 数据边界

页面读取的是当前学生、当前任务、当前课件的服务器资料。刷新或换设备不会清空已有图片；新身份创建时资料为空。此改版不注入示例图，不新增上传/审核记录，也不修改已保存测试资料、成绩、AI 额度或生图机会。

已提交和通过状态仍锁定编辑；修改必须重新打开并提交老师审核。截止和个人补交继续使用原服务端规则。上传的逐文件错误、成功项保留、提交结果确认与刷新失败保护不变。页面仍使用 preparationToken，课堂 launchToken 和完成记录逻辑不变。
