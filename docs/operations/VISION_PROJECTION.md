# 邛窑 -AI看见了什么：简约投屏

2026-10-25，默认投屏仅对本课件切换到图片为主的排版。入口保留学习记录的“打开投屏页”，新旧课件名称及历史运行短名均可识别。其他课程、烧窑/猜拳/问卷/自定义投屏保留既有路径。

## 展示与数据

- 只显示课件名称、学生姓名、实验图片、处理条件、AI判断、一条可见依据、学生观察。移除通用投屏的大分数卡、课程/课件/用时等重复信息、附件下载列表、评分细则、答题明细和模型技术编号。此项是投屏显示调整，没有改写原成绩或评分规则。
- 新提交的JSON附件保留每条记录的原始`image`画布数据和`projectionVersion: qiong-vision-images-v1`。原有PNG、TXT、JSON三附件流程、冻结快照、重试复用及COMPLETED确认不变。最多5次的新实验逐图显示，历史超过5条的已保存记录也不截断为5条。
- 旧云模型JSON没有逐次图片时，使用同份已保存PNG实验卡中的原图与最近有效单变量对照。豆包版本的实验卡布局固定为1440×1500，其中两个实际图片矩形为(65,180,620,414)、(755,180,620,414)；只展示已保存的像素，不用新素材重建旧实验。清楚提示旧记录只保留了这一组对照，不能补造其余实验图片。
- 更旧布局、缺少结构化数据或读取失败时回退完整历史实验卡；没有图片则显示明确的空状态。不猜测历史版式。
- JSON只加载本课件指定`experiment-data`文件，20MiB上限、10秒超时；平台标准附件路径通过当前学生/教师门户的同源API代理读取，避免记录中的data域名因跨域限制而失效。读取不附带凭据或Referrer，不放宽生产CORS。图片仅允许受限PNG/JPEG数据或无凭据HTTP/HTTPS；学生文字全部转义。

## 验收和发布

- 七项投屏自动化回归覆盖逐图展示、旧卡片实际像素、无图/加载失败回退、安全URL/文字、流式大小限制和同源附件代理。原保存重试测试补充逐次图片完整保存校验。
- 使用已有隔离学生真实记录，从正常成果详情点击投屏，核对两张实际图片、原AI结果和观察，检查1920×1080、1440×900、1024×768、390×844；不新增测试成绩，不调用付费模型。
- 本次同时发布平台静态前端和本课件前端；无API源码、数据库结构、权限或服务配置变更。先备份数据库、旧平台dist和课件运行目录，再Git快进。
- 平台前端在服务器私密暂存目录构建，先合并带哈希资源，再原子替换index.html，保留旧哈希资源供已打开页面继续使用。课件按原映射同步；无需重启主API、Nginx或视觉服务，不重置调用额度。
- 发布后刷新教师/学生后台，再关闭并重开旧投屏窗口。已打开的投屏是独立静态页面，不会自动更新。

回滚仅恢复匹配的旧平台入口/资源及课件前端，保留后来新增记录和全部图片附件，不整库恢复。
