# 烧窑学习成果投屏

2026-10-24：仅为《邛窑AI烧窑挑战》替换默认投屏排版，其他课件、猜拳专用投屏、YOLO问卷投屏和自定义投屏链接保持原路径。

## 数据与边界

- 入口仍为学习记录的“投屏”，由`apps/admin-web/src/App.tsx`打开独立窗口。专用渲染与解析位于`apps/admin-web/src/kiln-projection.ts`。
- 使用本次记录已有的`experiment-data`附件，原始文件名必须为`qiong-kiln-experiments.json`。读取超时10秒，最多8MiB；文件失败、格式不符、字段缺失时只用已有提交摘要回退，不补造曲线，不把缺失值写成0。
- 只读读取附件，不新增成绩、不重做训练、不调用付费AI。学生选择的发现、课程、姓名、用时和成绩来自原记录。
- 1.3.0新记录以`lessonFlow: manual-ai`标记：标题“手动与AI的实验对比”，展示手动及两种AI奖励；历史记录继续显示固定程序数据及三模式标题。标记同时写入JSON和平台摘要，附件不可读时仍能识别新流程。不删除或重写历史数据。
- 手动、历史固定程序标明单窑记录；AI标明测试样本数与平均能耗、步数。每组奖励显示最近一次训练的结果，重复训练保留在展开记录中。真实的0%和0能耗必须保留。
- 温度轨迹使用实际动作记录或训练后回放，不绘制预测数据。旧版内部热度按课件1.2.1同样的教学映射换算℃，新报告优先使用`temperatureCelsius`。该曲线不是实际窑炉热力学曲线。
- 窑场图复用课件的本地生成素材，由Vite打包为带哈希资源；注明“教学示意图，并非学生作品”。报告附件只显示紧凑链接，不使用大幅空白媒体预览。
- 所有学生文字转义，附件和图片URL只允许无账号密码的HTTP/HTTPS地址；不把HTML、JSON或异常堆栈作为作品展示。

## 发布与验收

- 本次为后台静态前端变更，无数据库迁移、API重启或课件服务重启。
- 发布前备份数据库及`apps/admin-web/dist`；服务器Git快进到验证提交后构建到私密暂存目录，先合并哈希资源、最后原子替换入口HTML。保留旧哈希资源，避免已经打开的后台临时缺少资源。
- 执行`npm run agent:check`，包含`scripts/kiln-projection.test.mjs`的8项回归；另检查1920×1080、1440×900、1024×768、768×1024、390×844。
- 隔离浏览器测试覆盖图片加载、4行模式对比、5次重复训练保留、实际Q-learning实验曲线、历史摘要回退、未评分、窄屏横向表格滚动和无页面横向溢出。未进行物理投影仪或iPad真机测试。
- 线上只读核对已有5次训练的历史提交：JSON附件200，学生/教师/管理员三域名CORS正常；不输出学生身份、附件访问链接或凭据。
- 已打开的旧投屏页是静态窗口，不会自动刷新。发布后先刷新学生或教师后台，再关闭旧投屏并重新打开；原记录可直接使用。

## 回滚

恢复发布前备份的入口HTML及匹配资源即可；不恢复数据库、不删除新学习记录。源码回滚遵循主发布手册。
